6 · Sync Assistant — push отклонён
Push отклонён: origin/main ушёл вперёд
Локально 2 неотправленных коммита (a91f3c2, 5d02e7b), на remote — 1 новый (c47e19a «docs: README — скриншоты»). Выберите, как синхронизироваться.
Рекомендуетсяистория останется линейной
Pull --rebase, затем Push
Ваши 2 коммита встанут поверх c47e19a. Конфликтов не ожидается.
git pull --rebase origin main && git push
Альтернатива
Merge, затем Push
Создаст merge-коммит; развилка сохранится в истории.
git pull --no-rebase origin main
Перезапись remote
Force push с защитой
Удалит c47e19a с origin. Только --force-with-lease; резервная ссылка refs/gitstream/backup/main позволит откатить.
git push --force-with-lease origin main

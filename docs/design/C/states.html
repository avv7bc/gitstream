06 · Sync Assistant — push отклонён
Push отклонён — non-fast-forward На origin/main есть 1 коммит, которого нет у вас: c90f4a2 «docs: README — скриншоты» · m.ivanova. Ваши 2 коммита не отправлены.
рекомендуемPull --rebase → Push
Переставит 2 ваших коммита поверх c90f4a2. Конфликтов не ожидается — файлы не пересекаются.
git pull --rebase origin main && git push
Merge → Push
Создаст merge-коммит; ваши коммиты останутся как есть.
git pull --no-rebase origin main
Только Fetch
Обновит origin/main — разберётесь вручную в графе.
git fetch origin
Force push (with lease)
Перезапишет 1 чужой коммит на origin/main. Перед этим — бэкап refs/gitstream/backup/main, откат в один клик.
git push --force-with-lease origin main

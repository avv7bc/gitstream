00Конвенции· легенда борда
Палитра · шаги
Push › origin › main. Tab следующий шаг, ⌫ назад. Push, Pull, Checkout, Upstream, Merge, Rebase.
Боковая панель 400 px
Формы из нескольких полей. Подтверждение опасного действия — блок внутри панели, без второго окна.
Компактное окно
Только Credential, SSH-ключ хоста и групповое удаление. Поповер — у своей кнопки.
$git push origin main①
вторичное ②③
① первая строка подвала — предпросмотр команды git, обновляется вживую
② слева — вторичное действие или подсказка клавиш
③ справа — [Отмена Esc] [Основное ↵]; при многострочном поле — Ctrl+↵
Тон кнопки: лайм — обычное, красный — необратимое, янтарь — доверие

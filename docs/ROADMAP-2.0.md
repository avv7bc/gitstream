# GitStream 2 — дорожная карта

Версия 2 = дизайн **A «Графит»** (холст: https://claude.ai/artifact/3CaA2te2nUCX6Egm3tt9gg) + новые функции из [SPEC-redesign-2026.md](SPEC-redesign-2026.md). Версия 1 продолжает жить в `release/1.x` (см. раздел «Версии и ветки» в CLAUDE.md).

Каждый этап ниже — отдельный детальный план в `docs/superpowers/plans/`, который пишется **перед началом этапа**, а не заранее: код к тому времени изменится. Этап заканчивается prerelease-тегом, чтобы новое можно было пощупать в реальной сборке.

Из других вариантов берём: палитру команд и kbd-подсказки (C), встроенную форму коммита как основной путь (B). Не берём: side-sheets вместо модалок, вкладки репозиториев, режимы «История / Изменения».

## Этап 2 — каркас окна и обратная связь → `2.0.0-alpha.2`
Спека §2.4, §2.6, §4.
1. Тосты (`useToast`, `ToastStack`); `logError` больше не переключает нижнюю панель.
2. Тулбар «Графит»: Fetch(split) · Pull ↓N · Push ↑N · **Коммит (N)** · место под Отменить · поиск/палитра · Stats · Settings.
3. Статус-бар на токенах: репо · ветка · ↑↓ · изменения · операция · последняя ошибка.

**Готово, когда:** главное окно совпадает с артбордом «A · Главное окно»; ни одна панель не пустая без объяснения.

## Этап 3 — команды и коммит → `2.0.0-alpha.3`
Спека §2.1, §3.3, §3.4, §3.5.
1. Реестр команд, `ContextMenu`, таблица хоткеев; удалить 4 копии CSS меню.
2. Меню только с применимыми пунктами; меню файлов коммита (история, blame, сравнить, восстановить, копировать путь, патч).
3. Push-диалог достижим (клик), быстрый push (Shift+клик / Alt+PgUp); Merge/Rebase в тулбаре активны.
4. Диалоги Merge и Rebase вместо прямого запуска / `window.confirm`.
5. Встроенная форма коммита под FileList; Ctrl+K — фокус, Ctrl+Shift+K — диалог.

**Готово, когда:** тулбар, меню и хоткеи строятся из реестра; коммит без диалога.

## Этап 4 — страховочная сеть → `2.0.0-beta.1`
Спека §3.1, §3.2.
1. `oplog.rs`: снимок refs/HEAD/индекса/рабочего дерева, обёртка `mutate()` для всех мутаций.
2. Undo / Redo (тулбар, Ctrl+Z, тост «Отменить»), вкладка «Операции».
3. Reflog: просмотр, «создать ветку здесь», «показать в графе».
4. Backup-ref Sync Assistant → частный случай oplog.

**Готово, когда:** интеграционные тесты на временных репо: reset --hard, branch delete, stash pop, discard, commit --amend — всё откатывается и возвращается.

## 2.0.0 — стабилизация
`beta.N` → `rc.N` → **2.0.0**: только баги, производительность (большие репо, 50k+ коммитов), ручной прогон по чек-листу всех артбордов «Графит». Начинается отсчёт поддержки v1.

## Зависимости

```
Этап 0 ─► Этап 1 ─► Этап 2 ─► Этап 3 ─► Этап 4 ─► 2.0.0
                                  │          │
                                  │          └─► 2.1 (правка истории требует Undo)
                                  └─► 2.1 (палитра требует реестр команд)
2.1 (прогноз конфликтов) ─► 2.2 (interactive rebase) ─► 2.3 (resolver переиспользует diff-движок)
```

Этапы 1–4 последовательны: каждый опирается на предыдущий (диалоги → тосты и каркас → реестр команд → oplog встраивается в мутации, уже вызываемые через реестр).

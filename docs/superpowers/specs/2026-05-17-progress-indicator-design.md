# Индикатор выполнения операций (>100 ms)

## Цель

Любая операция, выполняющаяся дольше 100 мс, должна отображаться в UI
ненавязчивой крутилкой. Покрытие — автоматическое для всех IPC-вызовов,
без ручной разметки в местах вызова.

## Решение (по итогам брейншторма)

- **Где показывать:** глобальный индикатор в `StatusBar` (крутилка + текст
  операции). Не блокирует UI.
- **Механизм:** единая обёртка над `invoke` — drop-in замена импорта во всех
  composables. «Любой процесс» покрывается автоматически.
- **Подпись:** конкретная операция по словарю `команда → RU-текст`; при
  нескольких параллельных — `Операций: N`.

## Архитектура

Новый модуль `src/composables/useProgress.ts`:

- Хранит глобальное состояние вне `setup()` (модульные `ref`/`Map`), как уже
  сделано в `useRemote.ts` (`isBusy = ref(false)` на уровне модуля).
- Экспортирует `invoke<T>(cmd, args?)` с сигнатурой, идентичной
  `@tauri-apps/api/core`, — внутри вызывает настоящий tauri-`invoke`.
- Экспортирует composable-функцию `useProgress()` → `{ isWorking, progressLabel }`.

Поток:

```
composable → invoke (из useProgress)
   │
   ├─ setTimeout(THRESHOLD_MS)
   ├─ realInvoke(cmd, args)
   │
   ├─ settle ДО 100 мс → clearTimeout, в active не попадает (нет мерцания)
   └─ таймер сработал, операция ещё жива → active.set(id, {...})
            └─ finally: active.delete(id); если таймер ещё висит — clearTimeout
```

### Подключение

Во всех composables, импортирующих `invoke`, заменяется только строка импорта:

```
- import { invoke } from "@tauri-apps/api/core";
+ import { invoke } from "@/composables/useProgress";
```

Затрагиваемые файлы (по grep на момент написания):
`useBranches.ts`, `useCommit.ts`, `useConflicts.ts`, `useDiff.ts`,
`useFiles.ts`, `useLog.ts`, `useRemote.ts`, `useRepo.ts`, `useSettings.ts`.
Тела вызовов `invoke(...)` не меняются.

## Состояние и API модуля

| Имя | Тип | Назначение |
|-----|-----|------------|
| `active` | `Map<number, { cmd: string; label: string }>` | операции, пережившие порог |
| `isWorking` | `ComputedRef<boolean>` | `active.size > 0` |
| `progressLabel` | `ComputedRef<string>` | при `size === 1` — метка операции; при `size > 1` — `Операций: ${size}` |
| `THRESHOLD_MS` | `const = 100` | порог в мс, константа модуля |
| `COMMAND_LABELS` | `Record<string, string>` | словарь `tauri-команда → RU-текст` |

`id` — монотонный счётчик (`let seq = 0; const id = ++seq`).

Запасная метка для команды, отсутствующей в `COMMAND_LABELS`, — `"Работаем…"`.

Начальный словарь (расширяется по мере надобности; ключи — реальные имена
tauri-команд):

| Команда | Подпись |
|---------|---------|
| `do_fetch` | `Fetch…` |
| `do_pull` | `Pull…` |
| `do_push` | `Push…` |
| `do_clone` | `Клонирование…` |
| `get_status` | `Статус файлов…` |
| `get_log` | `Загрузка лога…` |
| `stage_files` | `Stage…` |
| `unstage_files` | `Unstage…` |
| `discard_files` | `Discard…` |

Точный перечень команд выверяется по `src-tauri/src/commands.rs` на этапе
реализации; неизвестные просто получают запасную метку — корректность не
страдает.

## StatusBar

`.statusbar-center` переключается с `useRemote().isBusy` на `useProgress()`:

- приоритет `lastError` сохраняется (ошибка перекрывает индикатор);
- иначе при `isWorking` — анимированная SVG-крутилка (codicon `loading`,
  CSS `@keyframes spin`, переиспользуем класс `.codicon`) + `progressLabel`;
- иначе пусто.

`useRemote.isBusy` остаётся для блокировки собственных кнопок, но строку
состояния больше не формирует.

## Граничные случаи

- **Ошибка invoke:** `finally` чистит `active` и таймер → индикатор гаснет;
  ошибка пробрасывается вызывающему без изменений.
- **Параллельные операции:** каждая со своим `id` → корректный счётчик и
  переключение на `Операций: N`.
- **Частые быстрые вызовы** (`get_status` после каждой мутации): почти всегда
  укладываются в 100 мс → в `active` не попадают, мерцания нет.
- **Зависшая операция:** индикатор горит, пока промис не завершится; сетевые
  команды уже имеют собственный таймаут на стороне Rust — отдельной логики
  отмены здесь не вводим.

## Вне области

- Вынос порога в Settings (YAGNI).
- Отмена/прерывание операций из UI.
- Прогресс-проценты, оценка времени.

## Критерии готовности

- `npm run build` / проверка типов проходит без ошибок.
- Долгая операция (например `do_log` на большом репозитории, искусственная
  задержка) показывает крутилку с верной подписью в StatusBar.
- Быстрая операция (`get_status`) индикатор не зажигает.
- Две параллельные долгие операции → подпись `Операций: 2`.
- Ошибочная операция гасит индикатор и показывает `lastError`.
- Версия в заголовке (`StatusBar` `.version`) инкрементирована (patch).

# GitStream

Настольный Git-клиент с графическим интерфейсом. Фокус на повседневной работе с Git: коммиты, ветки, push/pull, просмотр изменений — без блокировок UI и лишней сложности.

## Что умеет

### Работа с файлами
- **Stage / Unstage / Discard** изменений одним кликом или через контекстное меню
- Статусы файлов: modified, added, deleted, renamed, untracked, conflicted
- Просмотр изменений в **unified** и **side-by-side** режимах с переключателем

### Коммиты
- Диалог коммита с таблицей файлов и чекбоксами — выбери что коммитить, не тронув индекс вручную
- Индикатор длины строки сообщения (50/72)
- **Amend** для исправления последнего коммита
- Кнопка **Commit & Push** — коммит и отправка в одно действие

### История
- Граф коммитов с ветками, тегами, HEAD и remote-трекингом
- Подсветка непушеных коммитов
- Строка Working Tree/Index поверх графа — двойной клик открывает диалог коммита
- Детали выбранного коммита: автор, дата, сообщение, изменённые файлы
- Фильтр коммитов по сообщению, автору, SHA, дате, ветке

### Ветки, теги, stash
- Список локальных и удалённых веток с индикаторами ahead/behind
- Checkout, переименование, удаление веток
- Checkout remote-ветки как новой локальной
- Теги и stash-записи в левой панели

### Удалённая работа
- **Pull** — merge или rebase, с выбором remote
- **Push** — с предупреждением о force push
- **Fetch** — получение изменений без интеграции

### Менеджер репозиториев
- Treeview открытых репозиториев с группировкой по папкам
- Drag-and-drop: репозитории в группы, группы друг в друга
- Двойной клик — переключение на репозиторий
- Контекстное меню: добавить репозиторий, создать группу, удалить

### Клавиатурные сокращения
- **Ctrl+K** — открыть диалог коммита
- **Ctrl+T** — stage выбранных файлов
- **Shift+Ctrl+T** — unstage выбранных файлов
- **Ctrl+M** — merge ветки
- **Ctrl+D** — rebase ветки
- **F7** — создать ветку
- **Shift+F7** — создать тег
- **Ctrl+A** — выделить все файлы в панели файлов

### Интерфейс
- Тулбар с выпадающими меню **Repository▾**, **Local▾**, **Branch▾** + кнопки Pull/Push/Fetch по центру
- Тёмная тема (Catppuccin-inspired)
- Перетаскиваемые модальные окна — таскай за заголовок
- Resizable-панели — подстрой под свой workflow
- Строка состояния: текущая ветка, ahead/behind, прогресс операций
- Индикатор прогресса сетевых операций с именем remote и обратным отсчётом до таймаута
- Все диалоги закрываются по Esc

## Технологии

- **Frontend:** Vue 3 (Composition API) + TypeScript + Vite
- **Backend:** Tauri 2 (Rust)
- **Git:** git CLI под капотом, парсинг `--porcelain` / `--format`

## Руководство по запуску

### Требования

- **Git** — должен быть в `PATH` (GitStream вызывает `git` напрямую)
- **Node.js** 18+ и **npm** — для frontend
- **Rust toolchain** — установи через [rustup.rs](https://rustup.rs/)
- **Системные зависимости Tauri** — см. [официальный гайд](https://tauri.app/start/prerequisites/):
  - **Linux:** `webkit2gtk`, `libgtk-3-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev`, `build-essential`
  - **macOS:** Xcode Command Line Tools
  - **Windows:** Microsoft Visual Studio C++ Build Tools + WebView2

### Быстрый запуск (автоматический)

В комплекте есть скрипт `start.sh`, который проверяет все зависимости, доустанавливает недостающие (Rust через rustup, системные пакеты через пакетный менеджер) и запускает приложение:

```bash
./start.sh          # режим разработки
./start.sh build    # production-сборка
```

Скрипт поддерживает apt, dnf, pacman, zypper и macOS. На каждый шаг установки спрашивает подтверждение.

### Установка вручную

```bash
git clone <repo-url> gitstream
cd gitstream
npm install
```

### Режим разработки

Запускает Vite dev-сервер + Tauri с горячей перезагрузкой:

```bash
npm run tauri dev
```

Первый запуск долгий — Rust компилирует зависимости. Последующие — быстрые.

### Production-сборка

Собирает оптимизированный бандл и нативный инсталлятор для текущей платформы:

```bash
npm run tauri build
```

Результат:
- **Linux:** `src-tauri/target/release/bundle/{deb,rpm,appimage}/`
- **macOS:** `src-tauri/target/release/bundle/{dmg,macos}/`
- **Windows:** `src-tauri/target/release/bundle/{msi,nsis}/`

### Первый запуск

1. Открой приложение — увидишь пустой менеджер репозиториев слева
2. Правый клик в панели `Repositories` → `Add Repository` → укажи путь к локальному Git-репозиторию
3. Двойной клик по репозиторию — переключение на него

### Полезные команды

```bash
npm run dev          # только Vite (без Tauri, для отладки UI)
npm run build        # type-check + сборка frontend
npx vue-tsc --noEmit # проверка TypeScript без сборки
```
